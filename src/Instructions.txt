COMMANDS

ຂໍ້ມູນນໍາເຂົ້າ variableName        -- input from console
ສ້າງ variableName        -- create a variable
ອ່ານ variableName        -- read value from a variable
ເກັບໄວ້ໃນ variableName value        -- set value to a variable
ປະກອບ variableResult variable1 "string1" "string2" variable2 ...        -- concatenate 2 or more strings and variables, saving to a variable
ຕົວເລກ variableResult variable1 operation variable2...        -- perform an operation with numbers or decimals between 2 or more variables or numbers, saving to a variable
